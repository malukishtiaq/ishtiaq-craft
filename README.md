# ishtiaq-craft

Personal Cursor setup: Taste Skill, Impeccable, Awesome DESIGN.md, and Img2ThreeJS.

On the work PC, install Git and Node.js, clone this repo, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\cursor-design-tools-setup.ps1
```

Start a new Cursor chat after the script finishes.
